# EsaveProject — AI-Powered Electricity Management Platform

## About the Project
EsaveProject is a team-based graduation project designed to help households monitor and manage their electricity consumption using AI-powered features.

The platform helps users understand their electricity usage, estimate their bills, and create personalized electricity-saving plans.

## My Role
I worked as a **Frontend Developer** alongside another frontend developer as part of the graduation project team.

My role focused on developing the frontend interface and implementing the user-facing features of the platform.

## Key Features
- **AI-Powered Meter Reading:** Extracting electricity meter readings from uploaded meter images.
- **Electricity Bill Prediction:** Estimating electricity bills based on available consumption data.
- **Personalized Electricity-Saving Plans:** Generating saving plans based on the user's target bill and appliance preferences.
- **Appliance Preferences:** Allowing users to specify which appliances they want to keep using when generating a saving plan.

## Installation and Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/shahd-muhmd/Graduation-Project.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Graduation-Project
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
